## Purpose

Primitive UI components generated by [shadcn/ui](https://ui.shadcn.com/). These are wrappers around Radix UI primitives styled with Tailwind CSS. They form the design system foundation that all other components build upon.

## Standards

- **Do not edit these files manually** — they are generated and maintained by shadcn/ui. Changes will be overwritten on the next `npx shadcn@latest add`.
- **Add new components with the CLI**: `npx shadcn@latest add <component-name>`.
- **Customize via CSS variables** — theme tokens (colors, radius, etc.) are defined in `app/globals.css` as CSS custom properties, not in these files.
- **These components do not fetch data** — they are purely presentational.
- **Import path**: `import { Button } from "@/components/ui/button"`.
